## 8. What to learn now (priority order)

Your fastest technical path = **Frontend Web Developer** (you already ship sites).

### Phase 1 — next 4–6 weeks (must)
| Learn | Why | Proof |
|-------|-----|--------|
| **JavaScript deep** (arrays, objects, DOM, fetch, async) | Moves you from “designer who codes” to developer | Rebuild one site feature without AI writing all of it |
| **Git + GitHub** daily | Every tech hiring screen | Push portfolio to GitHub with clean commits |
| **Responsive CSS** (Flexbox, Grid) | Interview + real work | Mobile checklist on every project |
| **Browser DevTools + debugging** | Separates juniors who ship from juniors who guess | Fix layout bugs live |

### Phase 2 — next 2–3 months
| Learn | Why |
|-------|-----|
| **React** (components, props, state, hooks basics) | Most frontend job filters |
| **TypeScript** basics | Better job match + fewer bugs |
| **Tailwind CSS** | Fast UI jobs / modern stacks |
| **Basic APIs** (REST, JSON) | Real apps, not only static pages |

### Phase 3 — optional later (don’t start here)
- Node.js / simple backend  
- Testing (Vitest)  
- Accessibility (a11y)  
- Light Python only if you later want automation — **not** full Data Science yet  

### Skip for now (won’t help your LinkedIn tech funnel)
- “Become a Data Scientist” crash courses  
- Random Java/DSA-only Amazon SDE grind (unless that’s a deliberate 6–12 month goal)  
- Claiming Agentic AI / ML on LinkedIn without shipped projects  

### Weekly study plan (realistic)
- **5 days × 90 min:** JS/React course + exercises  
- **1 project day:** ship one small feature to GitHub + LinkedIn post  
- **Use Cursor/Claude** to learn faster — but explain every change yourself  

### Certifications that help a bit (optional)

- Meta Front-End or Scrimba React (project-based)
