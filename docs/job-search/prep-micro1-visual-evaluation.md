---

## Before you click Start

- Quiet room, stable Wi‑Fi, **laptop** (not phone)

## What this job actually is

You review images/visuals used to **train AI**: quality, aesthetics, usefulness, guideline adherence. Write short, objective justifications. Not a Website Designer job — closer to **visual QA + annotation**. Flexible ~15 hrs/week remote contractor work. Good side income while applying to design roles.

## Likely questions → short answers

### 1. Tell me about your visual / design experience
- Padma Lights: product photos, catalogue presentation, what looks export-ready vs messy
- Portfolio + JAI Home Care: layout, hierarchy, mobile-first visuals
- Photoshop for web assets; HTML/CSS so I know how images fail on real sites (blur, wrong crop, slow load)

### 2. How do you evaluate image quality?
Use a checklist out loud:
1. **Clarity** — sharp vs soft/blurry  
2. **Composition** — subject centered/cropped; empty vs cluttered  
3. **Lighting / exposure** — too dark, blown highlights  
4. **Color** — natural vs oversaturated / wrong white balance  
5. **Usefulness** — does it help the task (e.g. show the product clearly)?  
6. **Guideline fit** — always follow their rubric over personal taste  

### 3. Example of giving written feedback (practice this)

**Bad:** “Looks ugly.”  
**Good:** “Reject — soft focus on the main subject; edges lack detail at 100% zoom. Background clutter competes with the product. Recommendation: reshoot with sharper focus on the fixture and a clean neutral backdrop.”

### 4. High volume / remote / 15+ hours
- Support + moderation trained me for repetitive review without losing accuracy
- Can block 2–3 hour sessions; IST flexible evenings/weekends if needed
- Independent, guideline-driven, escalate edge cases instead of guessing

### 5. Tools / imaging fundamentals
- Formats: JPG, PNG, WebP, SVG (for UI); know compression vs quality tradeoff
- Photoshop: crop, resize, basic color/levels for web
- Web: alt text, aspect ratio, retina sizing — mention briefly as bonus

### 6. Pattern recognition in datasets
- Concentrix: spotting repeated policy violations / spam patterns
- Design: same error repeating (e.g. always cropping heads, always low contrast text on images)
- Say: “I’d flag systemic issues to the team, not only one-off rejects.”

## During the exercise

1. **Read guidelines first** — quote them in your reasoning  
2. Be **consistent** — same standard on every sample  
3. Prefer **specific + actionable** over vague praise  
4. If unsure: “Borderline — needs human lead review because X”  
5. Don’t invent brand rules; stick to what they give you
