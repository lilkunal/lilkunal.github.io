Atul Shiv Shakti — Vedic astrology site

A premium marketing site for an astrologer: services, pricing, WhatsApp booking, and trust content — built as a React demo while the product and copy keep evolving.

Status: Demo on GitHub Pages — not a finished client launch. Features and content are still in progress.

Problem

Astrology practices need a mobile-first presence that feels trustworthy: clear services, prices, and a booking path that doesn’t force people through a PDF or Instagram DM maze.

What I built

  • Service cards (e.g. Kundali Vishleshan)
  • WhatsApp-oriented booking CTAs
  • Dual themes (cosmic / temple dawn)
  • Motion-led scroll presentation

Current state

  • Public React demo
  • Kundli / Panchang / Rashifal surfaces in progress
  • Client-ready polish still ongoing

My role

Design system, front-end implementation (React, TypeScript, Vite, Tailwind, Motion), and AI-assisted iteration with human QA on mobile and booking flow clarity.

Why this matters for hire

Shows I can ship a niche service business site with conversion-minded CTAs — and label demos honestly until the client is ready to go live.

Stack & process

React + Vite + Tailwind v4 + Motion. Deployed to GitHub Pages. Claude / Cursor for speed; I own direction, copy tone, and launch checklist.
