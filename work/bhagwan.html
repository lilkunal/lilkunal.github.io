Bhagwan

A cinematic cosmology of Indian gods and goddesses — first-person kathas, Hindi / English / Sanskrit, and a pandit’s shelves. Educational and devotional. Not mockery.

Status: Live personal product at /bhagwan/ — not a client deliverable. Grouped by cosmic function, not a court of rank.

Problem

Most “Hindu gods” sites are either a ranking chart or a calendar scrape. Neither explains 33 koti correctly, nor lets a deity speak in the first person.

What I built

  • 38 deity / asura / chiranjivi profiles
  • 56 first-person katha-blogs
  • EN / हि / सं language switcher
  • Hubs: 33 koti, Upaniṣads, lokas, astra-śāstra

Current state

  • Live on GitHub Pages
  • Vite + React + TypeScript
  • Cinematic Śiva portraits as the visual north star

My role

Product, copy, and full front-end. The literary frame is first-person kathas with traditional śloka openings where they are authentic. Asuras are treated with dharmic complexity, not cartoon “devils.” Astra-śāstra on the site is cultural literacy, not a weapons how-to.

Why this matters for hire

Shows I can ship a content-heavy React app with a real information architecture — not only brochure sites. Language switching, long-form reading, and a tone that has to stay respectful while still being cinematic.

Stack & process

Vite + React + TypeScript. Custom CSS (Cormorant Garamond, Syne, Noto Devanagari). GitHub Pages at /bhagwan/. Claude / Cursor for speed; I own the cosmology framing, the copy, and launch.
